## 🔤 Canonical wordmark typography (lock this in)

This is what I recommend you treat as final:

### Typeface

**Inter**

### Weight

**SemiBold (600)**
(Regular is too timid; Bold is too loud.)

### Case

`StashKit`
CamelCase is intentional and on-brand.

### Tracking / kerning

* Start at **–1%**
* Optical kerning **on**
* Do *not* manually kern unless you see a real collision

### Clear space

* Minimum clear space = height of the “S” in `StashKit`
* No elements intruding into that zone

### Lockup rules

* Default: **[ Delta ]  StashKit**
* Vertical stacking only when horizontal space is constrained
* Never place text inside the triangle
* Never overlap mark and wordmark

---

## Dark mode wordmark rules (important)

* Wordmark color = same as mark (`#E6EAF0`)
* No outlines
* No shadows
* No “softening” for readability

The typography should feel **as engineered as the symbol**.
